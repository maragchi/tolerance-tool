回转（摆动）气缸选型

按"转动惯量 → 角加速度 → 所需转矩（含重力矩）→ 动能校核 → 选型号"流程（经验公式源自亚德客手册）。

输入参数

可在 SolidWorks 质量属性中查询惯性张量（旋转中心置于坐标轴）
用于重力矩校核：T_g = m·g·r
重心偏离回转轴线的水平距离；无偏置填 0
齿轮齿条式一般 0~190°
一般取 5

计算结果与型号推荐

角加速度 α = 2θ/t²-
最大角速度 ωmax = 2θ/t-
其中重力矩 T_g = m·g·r-
★ 所需转矩 T = K·J·α + T_g-
负载最大动能 E = J·ω²/2-
★ 推荐型号（HRQ 齿轮齿条式）-
转矩随压力近似线性变化；表中为 0.5MPa 参考转矩，最终以厂家样本为准。动能超过允许值时须选带液压缓冲器规格（型号加 A）。

选型知识库

摘自教程资料的核心选型方法、公式与气缸分类。

一、双作用气缸选型六步法

步骤要点
1. 选定缸径确定轴向负载 F（水平 F=μmg，垂直 F=mg）→ 按运动状态选负载率 η → 确定使用压力 P（≤减压阀进口压力85%）→ 由 F=η·P·S 求活塞面积 S，换算缸径 D 并标准化
2. 选定行程按操作距离与传动机构行程比预选，留适当余量，尽量选标准行程（本表为厂商常用库存系列；GB/T 2349 第一系列为 25/50/80/100/125/160/200…；压紧工况吃进 3~5mm（毫米））
3. 选定品种按使用目的、缸径、行程从系列中选品种（标准/薄型/滑台/无杆/双杆…）
4. 选安装形式基本型、脚座型、杆侧/无杆侧法兰、单/双耳环、杆侧/无杆侧/中央耳轴
5. 选缓冲形式无缓冲、橡胶缓冲、气缓冲（可调）、外置液压缓冲器
6. 磁性开关位置检测用；前提是气缸内置磁环；安装方式有钢带式、轨道式、拉杆式、直接安装

二、核心计算公式

理论推力 Ft₁ = P·π·D²/4　　理论拉力 Ft₂ = P·π·(D²−d²)/4
负载率：阻性负载 0.8；惯性负载 v<100mm/s（毫米/秒） 取 0.65；v=100~500 取 0.5；v>500 取 0.35；垂直使用 ≤0.5
缸径反算 D = √(4F / (η·P·π))（推力侧）；拉力侧扣除杆径面积后求解
杆屈曲校核（受压工况）：Pcr = π²·E·I / L²，I = π·d⁴/64，E=206000MPa；安全载荷 = Pcr / n（本软件 n=4，两端铰支假设）
最大耗气量 Qmax = 6·Vmax·A·10⁻⁵ (L/min，压缩状态)；标准状态 Q = Qmax·(P+P₀)/P₀，P₀=0.1013MPa
空压机输出流量 Qc = K1·K2·K3·Q；本软件取值：漏损 K1=1.3（范围 1.15~1.5），备用 K2=1.4（范围 1.3~1.6），利用 K3=0.8（范围 0.5~1）
配管内径 d = √(4Q / (π·v))；主管路流速 8~10m/s，支管 10~15m/s
气罐容积（停机保压）V ≥ P₀·Q·T / (P1−P2)
回转气缸：角加速度 α=2θ/t²；所需转矩 T=K·J·α + m·g·r（K≈5，惯性矩带安全系数；m·g·r 为重心偏置重力矩）；最大角速度 ωmax=2θ/t；动能 E=J·ω²/2

三、气缸按结构分类（摘自资料）

类别名称使用特点
单作用气缸柱塞式柱塞外伸靠气压驱动，复位靠重力或外力
活塞式压缩空气单方向驱动，靠外力/重力/弹簧回复
薄膜式膜片代替活塞，弹簧回复，行程短、结构简单
双作用气缸普通气缸两方向均气压驱动，行程按需要选定
双活塞杆气缸两方向气压驱动，双向出杆
缓冲气缸（可调/不可调）临近行程终点减速防撞击；可调型缓冲效果可调
特殊气缸串联气缸多活塞串联，输出力为各活塞力之和，驱动力大
冲击气缸突然大量供气+快速排气，用于切断、冲孔、打击
多位/数字气缸活塞杆可停留在多个位置；行程按几何级数组合
伸缩气缸多活塞依次运动，适合较大工作行程
钢索式气缸钢丝绳代替刚性活塞杆，小直径特长行程（可达6m）
增压气缸 / 气液增压缸利用活塞面积差增大输出压力
气液阻尼缸气液联动，活塞杆运动平稳
伺服气缸气压信号成比例转换为位移，用于自动控制
