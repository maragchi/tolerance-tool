间隙配合

是什么：孔的公差带完全在轴的公差带之上，装配后总有间隙（最小间隙 ≥ 0）。

什么时候用：需要相对运动、转动，或经常拆装 —— 滑动轴承、机床导轨、导向柱、皮带轮与轴、齿轮在轴上滑移、定位销的导向段。

过渡配合

是什么：孔与轴的公差带相互交叠，装配后可能间隙、也可能过盈，取决于实际加工尺寸。

什么时候用：要求精确定位、又不常拆装 —— 齿轮/联轴器与轴、定位销的紧固段、蜗轮与轴、轴承的过渡配合部位。

过盈配合

是什么：轴的公差带完全在孔之上，装配后总有过盈，靠材料弹性变形传递扭矩、固定零件。

什么时候用：不拆装、靠过盈传力 —— 压装齿轮/蜗轮/叶轮、滚动轴承内圈与轴（紧配合）、销钉固定、车轮与轴。

配合代号怎么读

工程图上最常见的写法是 Φ50 H7/g6：前面是基本尺寸（50 mm），中间是大写 H7 表示孔的公差带， 后面小写 g6 表示轴的公差带。读法是"Φ50、孔 H7、轴 g6 的配合"。 大写字母与 IT 等级的组合叫公差带代号，孔用大写（H、K、N、P…），轴用小写（h、k、n、p…）， 这是 ISO 286 / GB/T 1800 的记法约定。

判断它属于间隙、过渡还是过盈，不用背公式：把孔和轴的公差带画在同一张图上比位置—— 孔的公差带完全落在轴上方＝间隙配合（总有间隙）；两条带互相交叠＝过渡配合（可能间隙也可能过盈）； 轴的公差带完全在孔上方＝过盈配合（总有过盈，靠弹性变形传力）。上面的公差带示意图就是按这个规则画的。

常用配合推荐（基孔制 H7，优先选用）

配合代号配合类型特点典型应用装配
H7/g6 间隙 最小间隙不为 0，能相对运动 滑动轴承、机床导轨、导向柱、传动轴与齿轮滑移 手装 / 轻推
H7/h6 间隙（最小 0） 定位准确，可反复拆装 定位销、法兰对中、皮带轮与轴、可拆定位件 手装
H7/js6 过渡 以定位为主，偶尔拆装 齿轮与轴、联轴器、蜗轮与轴 木锤 / 轻压
H7/k6 过渡 定位并传递较小扭矩 齿轮、蜗轮、飞轮、带轮与轴 压装
H7/n6 过渡（偏紧） 紧定位，能承受较大载荷 齿圈、衬套、定位套、承受冲击的定位件 压装
H7/p6 过盈 靠过盈传力，不常拆 滚动轴承内圈与轴、联轴器、销钉固定 压装 / 热装
H7/s6 过盈（较大） 重载，不拆连接 大型联轴器、车轮与轴、重载齿轮 热装 / 冷装

选配合的顺序：先看是否需要相对运动（要 → 间隙：g6 / h6），再看是否要定位并传递载荷 （定位为主 → js6 / k6；传递较大载荷 → n6），最后是不拆连接（p6 / s6）。 基轴制（如 Φ50 H7/h6 写成 Φ50 G7/h6）只在有标准件时使用，一般机械设计优先用基孔制。
