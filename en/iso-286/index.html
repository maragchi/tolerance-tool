THE NOTATION

What does H7/g6 mean?

H7 specifies the hole; g6 specifies the shaft. The letter locates the tolerance zone relative to the basic size. The number is the IT grade, which sets the zone width.

A hole-basis fit uses an H hole with zero lower deviation. A shaft-basis fit uses an h shaft with zero upper deviation.

Standards & scope

This calculator implements a selected metric subset: basic sizes 1–500 mm, grades IT5–IT13, and the D, E, F, G, H, JS, K, M, N, P, R and S zones and their shaft equivalents. Other classes are not offered. For N9–N13 holes, basic size must be greater than 1 mm.

Calculation references: ISO 286-1:2010 and ISO 286-2:2010. This is an independent implementation, not an ISO publication or certification.

Limits describe dimensional fits only. Surface texture, temperature, material, form, assembly force and functional suitability need separate engineering assessment.

How are clearance and interference calculated?

Minimum signed clearance = minimum hole size − maximum shaft size. Maximum signed clearance = maximum hole size − minimum shaft size. Negative signed clearance means interference. For an interference fit, the displayed interference magnitudes are positive.

Can I use an inch size or get an ANSI equivalent?

This version uses metric ISO classes only. Converting units does not turn an ISO fit into an ANSI/ASME B4.1 fit. An inch-fit calculator and cross-standard index are outside this version.

Why do adjacent sizes sometimes have the same result?

ISO tolerances use size intervals. An upper interval boundary belongs to that interval: 50 mm uses the above-30-to-50-mm IT range; a size just above 50 mm uses the next range. Fundamental deviations can use finer intervals.
